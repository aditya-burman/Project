📐 Linear Programming Model

Objective: Maximize Z = 6x₁ + 25x₂ + 18x₃ + 9x₄
Budget: 40x₁ + 150x₂ + 100x₃ + 50x₄ ≤ 500
Quantity limits: 0 ≤ x₁ ≤ 5; 0 ≤ x₂ ≤ 2; 0 ≤ x₃ ≤ 3; 0 ≤ x₄ ≤ 8
Integrality: x₁, x₂, x₃, x₄ must be integers.

x₁ = snacks, x₂ = movies, x₃ = games, x₄ = ₹50 savings units. Savings give future-security happiness points. The solver enumerates every feasible integer combination.
